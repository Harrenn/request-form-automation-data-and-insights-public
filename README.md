# Request form notifications

Google Apps Script that inserts review checkboxes and emails request/assignment updates when an authorized spreadsheet editor approves a row. Copy code into your own Apps Script project and configure its triggers for your form-response sheet.

Set NOTIFICATION_CC and REQUEST_SHEET_URL in Script Properties. This clean source-only copy replaces the internal company mailbox and private spreadsheet link. No form responses or credentials are included. Do not run authorization-mail tests unless you intend to send the configured test email.
